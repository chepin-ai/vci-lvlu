## A) 五共性中最深映射到自家机制的一条

若“贵线”指的是你联邦草案里那条 **11 线 = 边缘测度 · 协议层 = 耦合空间 · fail-closed = 凸性假设 · 公域 CI 通道 = 等距函子 · 级名不滥 = 单调量等号刚性 · ask 自包含 = 熵惩罚唯一性 · fp 互锚 = 距离 0 弱同构**，那我认为最深的是：

> **共性 3：最小假设最大正则。**
> 更具体地：**凸性/熵惩罚不是附加约束，而是把“多解耦合”压成“唯一可复现耦合”的机制。**

### 机制级对应

| OT 侧 | 贵线机制侧 |
|---|---|
| 边缘固定 + 联合优化 | 11 线边缘测度固定，协议层只在耦合空间里做联合选择 |
| 熵惩罚使 OT 耦合唯一 | `ask` 自包含：请求必须自带足够约束，使返回耦合唯一，而不是靠外部默认补全 |
| 凸性 alone 使边界正则/爆破齐次 | `fail-closed`：凸性假设一旦不成立，系统不是“近似继续”，而是关闭/拒绝，避免非唯一外推 |
| 松弛生结构 | 映射→耦合、酉→排列、超图→测度超网络；对应协议层把“实现细节”松弛成“耦合等价类” |
| 等号即分类 | `级名不滥`：单调量取等号才允许同一级名，否则只能降级或分裂 |
| 变换涌现而非假设 | `fp 互锚`：弱同构不是先验声明，而是距离 0 判定后涌现的等价关系 |

**最深的一点**不是“凸性”这个词，而是：

> **唯一性不是靠额外公理硬加，而是靠“凸性 + 边缘固定”这个最小结构自动涌现。**

这正好对应你元共性里那句：**变换涌现而非假设，定义改判为定理。**  
在贵线里，这意味着：

- 不应该先声明“这个协议是唯一的”；
- 而应该只声明边缘测度、耦合空间、凸性/fail-closed 条件；
- 唯一性、级名刚性、fp 互锚应当作为**判定结果**出现，而不是作为前提。

如果用一句话概括机制级对应：

> **凸性/fail-closed 是贵线的“熵惩罚”：它把多边界统一从“可以有”变成“只能这样有”。**

## B) 一个可操作可判定的「耦合/统一」实验

下面给一个最小实验，目标不是做大规模数值，而是**判定统一是否真的发生**，并且预期出现**刚性等号**。

### 实验名

**边缘固定下的耦合唯一性实验：ENTROPIC-COUPLING-RIGIDITY-01**

### 对象

取三类对象，各自只给“边缘”或“边界数据”，不给联合结构：

1. **概率边缘**：两个一维分布 \(\mu,\nu\)，只给边缘，不给耦合。
2. **图/超图边缘**：两个有限集上的超图关联结构，只给单顶点/单边边缘测度，不给联合超网络。
3. **贵线协议边缘**：两条 11 线的边缘测度/接口摘要，只给各自边缘，不给协议层耦合。

### 代价泛函

在耦合空间 \(\Pi(\mu,\nu)\) 上定义：

\[
\mathcal C_\varepsilon(\pi)
=
\underbrace{\int c(x,y)\,d\pi(x,y)}_{\text{基础代价}}
+
\varepsilon \underbrace{\mathrm{KL}(\pi \| \mu\otimes\nu)}_{\text{熵惩罚}}
\]

其中：

- \(c\) 是固定代价，例如距离平方、图编辑代价、协议不匹配代价；
- \(\varepsilon>0\) 是熵惩罚系数；
- 边缘约束：\(\pi\) 的第一、第二边缘分别等于给定边缘。

关键不是 \(\varepsilon\to 0\) 的极限，而是**固定 \(\varepsilon>0\)** 下的唯一性。

### 判定谓词

定义四个可判定谓词：

1. **存在性谓词**  
   \[
   P_{\text{exist}}:\quad \arg\min_{\pi\in\Pi(\mu,\nu)} \mathcal C_\varepsilon(\pi)\neq\varnothing
   \]

2. **唯一性谓词**  
   \[
   P_{\text{uniq}}:\quad |\arg\min \mathcal C_\varepsilon(\pi)|=1
   \]

3. **刚性等号谓词**  
   对单调量 \(M(\pi)\)，例如：

   - 概率侧：相对熵、协方差、传输距离；
   - 图侧：关联图距离、超边重叠度；
   - 贵线侧：级名不滥指标、fp 距离、ask 自包含度。

   检查：
   \[
   P_{\text{rigid}}:\quad M(\pi^\star)=\inf_\pi M(\pi)
   \]
   且该等号在边缘微扰下**保持到一阶**，即：
   \[
   \left.\frac{d}{dt}M(\pi^\star_t)\right|_{t=0}=0
   \]

4. **弱同构谓词**  
   若两个对象 \(A,B\) 的最优耦合 \(\pi^\star_{AB}\) 满足：
   \[
   \mathcal C_\varepsilon(\pi^\star_{AB})=0
   \]
   或更一般地：
   \[
   d_{\text{co-OT}}(A,B)=0
   \]
   则判定 \(A\simeq B\)，即弱同构。

### 实验流程

1. 固定边缘 \(\mu,\nu\)，不固定联合。
2. 选择 \(\varepsilon>0\)，计算 \(\pi^\star_\varepsilon\)。
3. 检查 \(P_{\text{exist}},P_{\text{uniq}}\)。
4. 对 \(\pi^\star_\varepsilon\) 计算单调量 \(M\)，检查 \(P_{\text{rigid}}\)。
5. 对两个不同对象 \(A,B\)，检查 \(d_{\text{co-OT}}(A,B)=0\) 是否等价于弱同构。
6. 重复微扰边缘，观察唯一性是否 fail-closed，刚性等号是否保持。

### 预期刚性等号

预期会出现三类刚性等号：

1. **唯一性等号**  
   \[
   \varepsilon>0 \implies \arg\min \mathcal C_\varepsilon \text{ 唯一}
   \]
   这正是熵惩罚把多解压成单解的机制。

2. **单调量等号**  
   对某个单调量 \(M\)，最优耦合处取到极值：
   \[
   M(\pi^\star)=\inf M
   \]
   且该等号不是偶然，而是由边缘固定 + 凸性保证。

3. **距离零等号**  
   \[
   d_{\text{co-OT}}(A,B)=0 \iff A\simeq B
   \]
   即弱同构不是假设，而是距离 0 的判定结果。

### 失败条件

如果出现以下任一情况，则“统一”不成立：

- \(\arg\min\) 不唯一；
- 刚性等号在微扰下立即破缺；
- \(d_{\text{co-OT}}=0\) 但对象不弱同构；
- 需要额外公理才能恢复唯一性。

这时按贵线机制应 **fail-closed**，不允许继续升级级名。
