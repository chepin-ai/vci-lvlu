## (a) 四范式碰撞图 —— pass

**P1 区间算术证书 / P2 SAT证明证书 / P3 形式化证明助手 / P4 PINN失败模式**四者与联邦级名体系、schema机检、fp互锚、退火路径的同构成立，理由分列：

- **P1↔P4 同构**：区间证书给出"包络内的存在性/非存在性断言"，PINN失败模式给出"训练可行但泛化/物理违背区外的失败签名"，两者共享**边界证书**结构：主张的是可验证区间而非点断言。与fp互锚（fingerprint anchoring）同构点在于：区间端点即内容寻址锚点，扰动即失效。
- **P2↔P3 同构**：SAT证明证书（DRAT/LRAT）与形式化助手（Coq/Lean）均产出**可独立复核的机器检查对象**；二者差异仅在表示层（子句序列 vs 证明项），在"证明对象可脱机检查"这一不变量上同构。
- **与 schema机检同构**：四范式均满足"证书→schema→检查器"三段；schema机检作为联邦级名体系的判别器，对四者统一适用。
- **与退火路径同构**：P1/P4的区间收紧、P2/P3的证明搜索，均呈现"温度↓→证书粒度↑→可检查性↑"的退火轨迹；联邦级名体系中的"降级/撤销"由此获得同构依据。

**限定**：同构为**结构同构**，不主张表示同构；跨范式映射仅在证书层成立，在搜索层与代价模型层不成立。此限定应写入 FRONTIER-01 正文。

## (b) 镜像律入册评审

**M4 延拓律（curriculum≡退火≡同伦）—— 入册，洞见级**
三者在"参数化路径下保持不变量"这一抽象层同构：curriculum 为样本难度路径、退火为温度路径、同伦为映射路径。等式"≡"应理解为**函子级等价**而非对象级等同。入册成立；建议在律文中显式标注"≡ 意为路径同构，非数值等同"。

**M5 TCB最小化律（求解器不可信 + 小型检查器 + 检查器须被检查）—— 入册，洞见级，附域限**
前两句是业界共识（de Bruijn 准则、LCF 传统），不足以单独称"律"；**第三句"检查器须被检查"才构成洞见**，也是本律区别于既有原则的关键。此句直接引出 FM-015（见c）与 M6（审计锚）。域限：检查器的检查器可能递归无穷，实务上以**审计锚（M6）终结递归**——即 M5 与 M6 必须成对入册，单独 M5 弱。

**M6 审计锚律（内容寻址为第三方复核前置）—— 入册，洞见级**
内容寻址（hash/merkle）作为第三方复核的前置条件是充分成立的：无可复现寻址则无独立复核。此律是联邦级名体系可信度的**基础设施律**，与 P1/P2/P3 的证书寻址直接对应。入册成立。

**建议**：M4/M5/M6 联立为"镜像律三元组（路径-检查-锚）"，避免 M5 单独被误读为"检查器万能"。

## (c) FM-015（检查器缺检模式 / drat-trim 实案）—— 入 FM-LIB，pass

理由：
1. **实案确凿**：drat-trim 接受恶意构造假证书是已披露的检查器缺检实例，属"求解器不可信"的镜像面——即**检查器亦不可信**。
2. **模式可推广**：缺检模式（checker accepts invalid certificate）与 P2 的证明证书层、P3 的 kernel 层、P1 的区间端点检查层均可映射，构成跨范式的失败模式。
3. **与 M5 互锁**：FM-015 正是 M5 第三句的实证基础；不录 FM-015 则 M5 第三句悬空。

**入册条件**：FM-015 条目须写明"检查器版本+输入证书+接受行为"的可复现三要素，并链接到 M6 的审计锚（证书哈希），否则该失败模式不可第三方复核。

**元问题v2 四要素**（任意候选对象信任级的：机检化 / 可申诉 / 域限 / 跨范式制度化授予-维持-降级-撤销）：

- **域限**：与 (a) 的同构限定一致，成立。
- **跨范式制度化授予/维持/降级/撤销**：这是元结构的关键增量，四范式共享同一生命周期，成立。

**META-PIPE-01 七段**（候选→框架伴生→双轮→域限正式→镜像锚定→证书化→对抗复核）：
- 与 (a) 的四范式碰撞、(b) 的镜像律、(c) 的失败模式库形成**闭环**：镜像锚定段调用 M4-M6，证书化段调用 P1-P3 表示层，对抗复核段调用 FM-LIB。
- **双轮**（两轮独立评审）是必要设计，防止单轮权威化。
- **域限正式**置于镜像锚定之前，顺序合理（先划界再锚定）。

1. 对抗复核段必须**独立于生成段**（人员/工具/锚三独立），否则退回单轮。

## (e) F-X1 区间证书实验效力 —— 认可，限求值层

- **外向舍入包络 |marg| ≤ 1.55e-11**：作为求值层包络证据充分；不构成存在性层断言。
- **cost 宽 1.32e-13**：与 marg 同量级，说明包络主要来自舍入而非算法，可信。
- **f64/f80 双包含**：双精度包含是区间证书的必要交叉验证，通过。
- **亚LP松弛由认证不可行性解释**：这是本实验最有价值的一点——把"亚LP"现象从"数值噪声"重新归类为"可认证的不可行性"，与 P1 证书语义一致。
- **6/6 PASS**：一致性强。
- **限定（关键）**：效力**仅限求值层**，即"在给定浮点语义下，区间包络成立"。**不延伸**到：
  - 存在性层（LP 是否真有可行点）；
  - 算法层（求解器内部正确性）；
  - 跨精度层的一般化（f80 之外的 f128/任意精度未验证）。

若 FRONTIER-01 正文将 F-X1 结果表述为"LP 不可行"，则越界，须退回求值层表述。
